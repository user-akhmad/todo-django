# TODO-приложение на Django

Учебный проект: список задач с возможностью добавлять, отмечать выполненными и удалять.

## 🛠 Технологии

- Python 3.14
- Django 6.1
- SQLite
- HTML/CSS

## ⚡ Функционал

- ✅ Создание задач через форму на сайте
- ✅ Отметка задач как выполненных
- ✅ Удаление задач
- ✅ Страницы «Активные» и «Выполненные»
- ✅ Админ-панель Django

## 🚀 Как запустить локально

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/ВАШ-ЛОГИН/todo-django.git
   cd todo-django
   ```
